# 小柠檬内核 完整版教程（全链路部署 · 保姆级）

> 版本 release-261117 ｜ 目标：从零把内核跑起来并让 MCP 客户端连上。每一步都给"命令 + 预期输出 + 失败怎么办"。

> 约定：所有 Termux 命令在**普通 Termux 会话**执行（不要 su 到 root 跑 pkg）；需要 root 的步骤会单独标注 `su -c`。

## 0. 心智模型（先看懂再动手）

数据流（自外向内）：

```
MCP客户端(AI/IDE)
   │  HTTPS + Authorization: Bearer <令牌>
   ▼
公网隧道(cloudflared/frp/zeronews)   ← 见《公网MCP自建教程》
   ▼
令牌闸 127.0.0.1:8796  (mcp_gate_8787.py, 校验Bearer)
   ▼
slim门面 127.0.0.1:8792 (slim_proxy_v154.py, MCP协议/异步任务/输出门禁)
   ▼
lemoncore 127.0.0.1:8788 (C核心, 工具注册表+执行)  ──► Java卫星 8790 / 插件脚本
```

端口速记：8788核心 / 8790 Java / 8791+8792 slim / 8794面板 / 8796闸 / 8786+8787 MT(可选)。
**全部只监听 127.0.0.1**；对外只经 8796 + 隧道。safe(8793)/guard 为闭源可选件，开源版跳过。

## 1. 环境准备

### 1.1 手机
1. root 确认：`su -c id` → `uid=0(root)`。无 root 请先刷 Magisk/KernelSU。
2. 装 Termux（F-Droid/GitHub 官方包）。
3. 设置→应用→Termux→电池→**无限制**；授予存储权限。
4. 可选：Termux:API、Termux:Boot。

### 1.2 Termux 基础包
```bash
pkg update && pkg upgrade -y
pkg install -y python clang git tmux unzip curl
termux-setup-storage     # 弹窗点"允许"
termux-wake-lock         # 防休眠
```
预期：`python3 --version` 有输出；`clang --version` 有输出。
失败：pkg 报 root 拒绝 → 你在 root shell 里了，退出回普通 Termux 再跑；网络慢 → `termux-change-repo` 换 TUNA。

## 8. 开机自启

## 9. 连接 MCP 客户端

客户端 MCP 配置（HTTP）：
```json
{"mcpServers":{"lemon-kernel":{"url":"http://127.0.0.1:8796/","headers":{"Authorization":"Bearer <你的令牌>"}}}}
```
远程：url 换隧道 HTTPS 地址（见《公网MCP自建教程》）。
连通测试：`tools/list` 返回工具即成功。

## 10. 调用示例

只读：`tools/call {"name":"tool_call","arguments":{"id":"sys_info","arguments":{}}}`
破坏性：arguments 里加 `"confirm":"1"`（开源版无 safe 层时由 cmdguard 白名单约束，仍请谨慎+备份）。
长任务：`task_submit` → `task_status` → `task_result`（避免同步超时）。
