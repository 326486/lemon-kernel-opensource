## 一、它是什么

小柠檬内核（LemonCore）= 跑在**已 root 的 Android 手机**上的 **MCP 工具内核**。把手机的系统/逆向/联网/设备控制能力封装成标准 MCP 工具，供 AI 助手/IDE/自研 Agent 发现与调用，让 AI 真正操作手机。
特点：on-device（不依赖云）、MCP 标准协议、安全分层、插件热扩展。

## 六、核心功能用法

- 发现：`tools/list`；检索 `tool_find`；看schema `tool_get`。
- 调用：`tool_call {id, arguments}`；破坏性加 `confirm:"1"`。
- 长任务：`task_submit{tool,arguments}`→`task_status{task_id}`→`task_result{task_id}`。
- 热加载插件：`kernel/reload`（**会重排T编号→用工具名调用**）。
- 面板(8794)：工具列表(搜索/域/风险/收藏/最近/表单调用)、监控(服务+延迟+仪表+告警)、审计(统计+明细+筛选+复制)、知识搜索/系统/日志。
- 面板APP：prebuilt/lemon-panel.apk 免编译直装(需后端在跑)。

## 七、安全机制

- 令牌闸：Bearer校验；错令牌防御性-32001。
- cmdguard：命令白/黑名单。
- 输出门禁：slim限制单次输出大小(防撑爆)。
- safe(可选，源码已开源、默认不启动)：确认门+路径保护+全量审计。
- guard(可选，源码不在本仓库)：内核级目录/磁盘防护；开源版以 08-guard-userspace 用户态检测+恢复替代。
- 开源版无safe时：破坏性操作靠cmdguard+调用方自觉confirm+备份。

## 八、FAQ

- 连不上/-32001：令牌错或闸没起。
- 工具空/骨架：后端没起或前端JS错；看panel.log与/api/overview。
- 后台被杀：电池无限制+wake-lock+Magisk固化。
- 长任务超时：改task_submit。
- 抓被WAF拦：nettools内置acw求解；换源/降频。
- pm install失败：cp到/data/local/tmp再装(SELinux)。
更多见《部署排错手册》。
