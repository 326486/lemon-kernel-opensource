# 小柠檬内核 部署排错手册（逐条对照）

> 用法：按"现象"找条目，照"原因/处理"做。每条给验证命令。覆盖作者实测踩过的全部坑。

## A. 连接 / 鉴权

**A1 返回 -32001 not found**
原因：Bearer 令牌错 / 令牌闸没起 / 用了旧令牌。
处理：核对 tokens.json 与客户端 header 一致；`pgrep -f mcp_gate` 有 pid；重启闸 `sh start.sh`。
验证：curl 8796 initialize 带正确 Bearer → serverInfo。

**A2 connection refused / 超时**
原因：对应进程没起或被系统杀。
处理：看进程 `pgrep -f lemoncore / slim_proxy / mcp_gate`；没起就启动；被杀→电池无限制+wake-lock+看门狗。
验证：`netstat -tlnp | grep 8788` 等端口在听。

**A3 公网连不上但本机正常**
原因：隧道没起/域名变/缓冲。
处理：见《公网MCP自建教程》自检表；cloudflared 临时域名每次重启会变→重取 URL；nginx 必须 proxy_buffering off。

## B. 面板 / 前端

**B1 面板骨架屏 / 总数0 / 工具区空**
原因：后端没起 或 前端 JS 报错 或 加载瞬间截图。
处理：`curl 127.0.0.1:8794/api/overview` 看 total；看 panel.log；等几秒自动重试；点"重试"。若 JS 错→看浏览器 console / 重新拉最新 panel_ui.html。
验证：/api/overview total>0 且 / 返回含工具卡片 HTML。

**B2 面板 APP 打开空白/加载失败**
原因：后端 8794 没起；或 WebView 缓存旧页。
处理：先起后端；APP 强制停止再开（clearCache）；确认 URL 127.0.0.1:8794。

**B3 面板右侧被裁切 / 顶部被状态栏挡**
原因：旧版 APK 布局问题。
处理：用最新 prebuilt APK（已修：无 LAYOUT_FULLSCREEN、clearCache、setTextZoom(100)、grid minmax(0,1fr)）。重编/重装最新 apk。

## C. 工具 / 插件

**C1 tools/list 空 / 插件不生效**
原因：插件没 reload。
处理：`kernel/reload`；确认 JSON 在 plugins 目录。
验证：reload 返回 total 增加。

**C2 调用报"未找到 T-xxxx"**
原因：reload 重排了 T 编号。
处理：**改用工具名**调用（tool_call id=工具名），别用 T 编号。

**C3 长任务同步超时**
处理：改 `task_submit`→`task_status`→`task_result` 异步三段。

**C4 同步 shell 查询 backend unreachable 但 initialize 正常**
原因：某个长 shell（如 git push）占住同步 shell worker。
处理：改用 `task_submit`(异步)跑长命令 + `task_result` 轮询；别在长任务期间发同步 shell。
注意：`pkill -f "git push"` 会误杀含该字样的自身 shell→用括号技巧 `pkill -f 'git [p]ush'` / `git-remote-[h]ttps`。

## D. 安装 / 系统

**D1 pm install 报 SELinux / can't open file**
原因：system_server 读不了 /data/lemonbrain 下 apk。
处理：`cp xx.apk /data/local/tmp/` 再 `pm install -r /data/local/tmp/xx.apk`。

**D2 pkg 报 "cannot run as root"**
原因：在 root shell 跑 pkg。
处理：回普通 Termux 会话跑 pkg；或需 root 的安装用 `su -c` 单独命令。

**D3 Termux 存储权限拒绝 / setup-storage 无反应**
处理：手机设置→应用→Termux→权限→存储 手动允许。

**D4 后台进程常被杀（ColorOS/MIUI）**
处理：电池无限制 + `termux-wake-lock` + 看门狗 + Magisk 固化(service.sh) + Termux:Boot。

**D5 python3 找不到**
处理：用全路径 `/data/data/com.termux/files/usr/bin/python3`；或 `export PATH=/data/data/com.termux/files/usr/bin:$PATH`。

## E. 编译 / 内核

**E1 lemoncore 编译失败**
处理：看 build_warn.log；确认 clang 已装、架构 arm64；或用包内匹配预编译二进制。

**E2 guard insmod 后不开机 / 拒绝加载**
原因：.ko 与设备内核版本不匹配。
处理：**切勿**加载不匹配 ko；先备份 boot；用 QEMU 真内核验证后再 insmod；新手跳过 guard（源码不在本仓库；用户态替代见 08-guard-userspace）。

## F. 传输 / 打包

**F1 base64 回传二进制丢字节/损坏**
原因：输出脱敏器把40+连续字母数字(base64长行)打码。
处理：传二进制用带空格十六进制 `od -An -v -tx1`（空格打断连续串），或直接在设备端交付文件；回传后 md5+字节数+文件数三重校验。

**F2 发布包"docs 缺失/MANIFEST 空承诺"**
原因：打包时 docs 没进 staging 或 push 前没 add。
处理：确认 staging/docs 存在→git add -A→commit→push；用 `git ls-tree origin main docs/` 校验远端确有 docs。

**F3 git push  hang / 占住通道**
处理：用 task_submit 异步 push；push 耗时长属正常；完成后 `git remote set-url origin https://...`(去掉token)。

## G. 抓取 / 联网

**G1 web_fetch 被 WAF(acw) 拦**
处理：nettools 内置 acw_sc__v2 求解；仍失败换源/降频/加 cookie。

**G2 搜索源不可用**
处理：search.conf 换源；web_search 多源回退。

## H. 凭据安全

**H1 令牌泄露怀疑**
处理：改 tokens.json 换新随机串+重启闸；旧令牌即失效； revoke 相关 PAT。

**H2 PAT 用于 push 后**
处理：push 完到 GitHub revoke/轮换该 PAT；remote 重置为无 token https。
